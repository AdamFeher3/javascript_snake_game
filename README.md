<h1>JavaScript Snake Game</h1>
<p>A simple snake game built with HTML, CSS and JavaScript</p>
<h2>How to play</h2>
<p>
  Use Arrow keys or WASD to move snake<br/>
  On mobile swipe on screen to move snake<br/>
  Press P to pause the game
</p>
